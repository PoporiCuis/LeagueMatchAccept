# LoL Match Assistant

A Python desktop companion for the League of Legends client. It can accept match queues, automate champion picks and bans, use role-specific champion profiles, and run from the system tray.

## Downloads

- **Latest version:** [Download the ready-to-run ZIP from Google Drive](https://drive.google.com/file/d/1V9M434u4QJnDS5xSfDh_dw13NkvwKzZI/view?usp=sharing).
- **Legacy / pre-release version:** [Download the older build from Google Drive](https://drive.google.com/file/d/1lMAi-d6wulYdh1mV9hQPojvCfp8IJeU6/view?usp=sharing)

The latest Windows package is a ZIP containing the ready-to-run executable. No Python installation is needed to run it.

## Run from source

1. Install Python.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run `python main.py` while the League client is open.

## Build for Windows

Run `BUILD_RELEASE.bat` from this folder. It creates `LoLMatchAssistant_Release` on the Desktop.
